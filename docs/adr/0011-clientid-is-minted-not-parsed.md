# 11. `ClientId` is a server-minted identifier constructed totally, not parsed from untrusted input

## Status

Accepted

## Context

A guideline enforced by the analyser requires a `from*` named constructor that returns the type it builds to return an optional (`?self`) rather than the type non-nullably: a parser of untrusted external input must report bad input as a value the caller is forced to handle, never by throwing or by pretending construction is total.

`ClientId` is not such a parser. It is the relay's own handle for a live connection, minted inside the process:

- `fromBytes()` hex-encodes bytes drawn from the server's random source when a connection is registered. The input is generated by the relay itself, and hex-encoding is total — there is no bad input.
- `fromString()` reconstructs the id from that same opaque hex form. The value carries no protocol-level validity constraint the relay could check or reject; any string is a usable key.

There is no untrusted external input here and no failure mode to model, so returning `?self` would invent a `null` branch that can never occur and force every caller to handle an outcome that does not exist.

## Decision

`ClientId`'s named constructors return `self` — construction is total. They are fenced as trusted, server-minted construction, distinct from parsing untrusted input. The guideline continues to govern every value object that *does* parse external input (`PublicKey`, `EventId`, `IpAddress`, …), which return `?self`.

## Consequences

- The analyser flags `ClientId`'s non-nullable `from*` constructors; the fence marks them as a deliberate exception because the id is minted, not parsed.
- A reviewer must not "fix" them into `?self` to satisfy the guideline uniformly — there is no bad-input case to report, so the nullable branch would be dead and every call site would carry a handling path for an outcome that cannot arise.
- If `ClientId` ever gains a genuine validity constraint or is built from untrusted external input, this decision no longer applies and it must return `?self` like any other parser.
